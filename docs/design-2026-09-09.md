# 2026-09-09 Studio 改版

## 设计

- 从通用工作台照片、装饰性色块和多层卡片，改为 NQ 个人标识、黑白中性色与朱红重点色。
- 保留项目、筛选、建设计划、记录、关于、联系方式和详情弹窗。
- 金融项目直接呈现固定版本报告中的干扰行混入率；明确保留 3 份合成文档、4 个用例和 50% 用例通过率。
- 量化项目展示验证状态，不绘制没有依据的收益曲线。
- 学习与音乐采用次级项目布局；未实现内容继续标注计划中。
- 未重新运行金融或量化实验，既有报告链接和结果范围不变。

## 交互修复

- Ctrl/Cmd/Shift/Alt 点击项目不再被弹窗拦截。
- 详情工具栏与滚动区分离，长内容滚到底部仍可关闭。
- 关闭后保留页面滚动位置并恢复触发链接焦点；重新打开重置详情滚动。
- 仅完整发生在遮罩上的点击关闭弹窗，避免内容选取被误认为关闭操作。
- 已保存的主题在样式加载前应用；受限存储不会阻断页面。
- 到达页面底部时高亮联系导航；筛选结果通过 aria-live 公告。
- 移除依赖滚动观察器才能显现内容的动画。

## 验证

运行 `npm run check` 和 `npm test`。浏览器检查为 14 个场景 × 7 种视口；以 GitHub Actions 的实际结果为准。截图必须人工检查，测试通过不等于视觉设计自动合格。发布前还需确认线上 HTML、CSS、JS 与本地提交一致。
